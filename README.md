# 数式グラフ化学習ツール

学校で習う数式をグラフにして、数を動かしながら変化を確かめるWebアプリです。
学習用に役立ててもらうことを目的とし、再利用・改変・改善を歓迎します。

**試験公開中です。** 計算・表示に不具合が残っている可能性があります。
解法の提示や採点は行いません。結果は教科書や自分の計算と照らし合わせてください。
入力した式は保存されず、再読み込みすると消えます。

## 試す

[アプリを開く](https://cpulse621.github.io/formula-graph-learning-tool/)

「式を追加」から選び、式の数字の箱を押して値を調整します。
「確かめる」をオンにすると、座標や周期などの確認用の数値が表示されます。

三角関数、二次・三次関数、指数・対数、分数関数、平方根、絶対値、円、直線の3つの形、単位円に対応します。
スマホでは上にグラフ・下に式、PCでは左に式・右にグラフを表示します。

## 開発する

Node.js 24.15以降の24系とnpmを使用します。

```sh
npm ci
npm run dev
npm test
npm run build
```

ブラウザのテストも実行できます。

```sh
npx playwright install chromium webkit
npm run test:e2e
```

式の定義は `src/data/`、数学の計算は `src/math/`、SVGの描画は `src/graph/` にあります。
計算を変更した場合は対応するテストも追加してください。

## 公開

`main` への更新後、GitHub Actionsでテスト・ビルドが成功した場合だけGitHub Pagesへ公開します。
公開されるのは `dist/` のファイルで、開発メモや端末固有の設定は含めません。
認証キーをコードや履歴へ保存しないでください。
